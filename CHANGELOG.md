# Changelog

All notable Atlas changes are recorded here. Atlas follows semantic versioning.

## [Unreleased]

### Added

- Production-oriented deployment, verification, backup, and release tooling.
- Revocable account sessions with Argon2 password hashing.
- A release-readiness audit and explicit capability boundaries.

### Security

- Production configuration rejects development secrets and credentials.
- Atlas-owned AI remains the only enabled inference path.

## [0.1.0] - 2026-08-16

### Added

- Atlas desktop shell and unified Chat, Image, Code, Search, Files, Projects, and Settings areas.
- Atlas Native local language-model service and checkpoint format.
- Secure Electron IPC bridge and VS Code companion extension.
- FastAPI, PostgreSQL, Redis, pgvector, migrations, health checks, and knowledge-source access controls.
